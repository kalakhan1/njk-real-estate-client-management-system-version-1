Quick Start

  1. Dashboard par 4 tabs: Sab / Active / Inactive / Current Working
  2. Add Client se naya client add karein — Area + Area Size (sqft/sqyds/sqmtr/acres) bharein
  3. Client ke naam par click → poori detail
  4. Detail page par services add karein
  5. Search page par professional filters + Min/Max area size se target karein
  6. Settings se UI Language (Roman/English) toggle karein

FAQ

Current Working kya hai?
Active clients me toggle ON karne par woh Current Working tab me bhi dikhta hai.
UI Language toggle kya karta hai?
Poora app UI (nav, labels, placeholders) Roman Urdu ya English me badal jata hai.
Area Size range filter kaise use karein?
Search page par Min/Max values dein aur unit (sqft etc) select karein — matching clients filter ho jayenge.
